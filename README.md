# My Counter App 🔢

A simple beginner-friendly Counter App built while learning the basics of web development.

## About

This project allows users to:

* ➕ Increase the counter
* ➖ Decrease the counter
* 🔄 Reset the counter to 0
* 🚫 Prevent the counter from going below 0

## Technologies Used

* HTML
* CSS
* JavaScript

## What I Learned

Through this project, I practiced:

* Creating a webpage using HTML
* Styling a webpage using CSS
* Connecting JavaScript to HTML
* Using variables in JavaScript
* Using `getElementById()`
* Handling button clicks with `onclick`
* Updating webpage content using `textContent`
* Using `if` statements
* Organizing a project into separate HTML, CSS, and JavaScript files
